# DOS Disassembly Guide

This guide covers DOS-specific features and usage of retrodisasm.

## DOS Features

* **Execution Flow Tracing** - Differentiates between code and data through program flow analysis
* **x86 16-bit Support** - Handles 8086/8088 instructions in 16-bit real mode
* **NASM Output** - Generates [NASM](https://www.nasm.us/) compatible assembly
* **Configurable Base Address** - Support for custom base addresses with `-base` flag

## DOS .com File Format

DOS .com files are simple executable programs for MS-DOS:
- Load at segment offset `0x0100` (with PSP at `0x0000`-`0x00FF`)
- Use 16-bit real mode x86 instructions
- Maximum size of ~64KB (one segment)
- Stored as raw binary without headers

## Usage

### Basic Disassembly

Auto-detection from `.com` extension:
```bash
retrodisasm -o output.asm program.com
```

Explicit system specification:
```bash
retrodisasm -s dos -o output.asm program.bin
```

### Assembler

DOS disassembly only supports the NASM format:
```bash
retrodisasm -a nasm -o output.asm program.com
```

### Example Output

```asm
; DOS .com file disassembly
; Generated by retrodisasm

bits 16
org 0x0100

Start:
    mov ah, 0x09                 ; $0100 B4 09
    mov dx, message              ; $0102 BA 0E 01
    int 0x21                     ; $0105 CD 21
    mov ax, 0x4C00               ; $0107 B8 00 4C
    int 0x21                     ; $010A CD 21

message:
    db 'Hello, World!$'
```

### Reassembly

After disassembly, reassemble with NASM:
```bash
nasm output.asm -o output.com
```

## DOS-Specific Options

### Custom Base Address

Specify a custom base address (default: `0x0100`):
```bash
retrodisasm -base 0x0200 -o output.asm program.com
```

This is useful for:
- COM files loaded at non-standard addresses
- Position-independent code
- TSR (Terminate and Stay Resident) programs

### Binary Mode

Disassemble raw binary as DOS code:
```bash
retrodisasm -s dos -binary -base 0x0100 -o output.asm code.bin
```

## Batch Processing

Process multiple DOS executables:
```bash
retrodisasm -s dos -batch "*.com"
```

## Output Customization

### Remove Comments

Omit hex opcode bytes in comments:
```bash
retrodisasm -s dos -nohexcomments -o output.asm program.com
```

Omit file offsets in comments:
```bash
retrodisasm -s dos -nooffsets -o output.asm program.com
```

## x86 Instruction Set

retrodisasm supports 8086/8088 instructions including:

**Data Transfer:**
- `MOV`, `PUSH`, `POP`, `XCHG`
- `IN`, `OUT`
- `LEA`, `LDS`, `LES`

**Arithmetic:**
- `ADD`, `SUB`, `ADC`, `SBB`
- `INC`, `DEC`, `NEG`
- `MUL`, `IMUL`, `DIV`, `IDIV`
- `CMP`

**Logic:**
- `AND`, `OR`, `XOR`, `NOT`
- `TEST`
- `SHL`, `SHR`, `SAL`, `SAR`, `ROL`, `ROR`, `RCL`, `RCR`

**Control Flow:**
- `JMP`, `Jcc` (conditional jumps)
- `CALL`, `RET`
- `LOOP`, `LOOPZ`, `LOOPNZ`
- `INT`, `IRET`

**String Operations:**
- `MOVS`, `CMPS`, `SCAS`, `LODS`, `STOS`
- `REP`, `REPE`, `REPNE`

**Flags:**
- `CLC`, `STC`, `CMC`
- `CLD`, `STD`
- `CLI`, `STI`
- `LAHF`, `SAHF`

## Known Limitations

* 8086/8088 instruction set only (no 80186+ instructions)
* Does not automatically detect DOS API calls or system functions
* PSP (Program Segment Prefix) structure is not disassembled
* No verification support (reassembly comparison not yet implemented)
